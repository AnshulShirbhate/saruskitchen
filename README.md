Application Prerequisites:<br />

Inside .env file add these values<br /><br />

// App Configurations<br />
NEXT_PUBLIC_APP_NAME=<br /><br />

//Database Configurations
DATABASE_URL=<br /><br />

// JWT Configurations<br />
JWT_SECRET=<br />
EMAIL_JWT_SECRET=<br /><br />

// Cloudinary Configurations<br />
CLOUDINARY_CLOUD_NAME=<br />
CLOUDINARY_API_KEY=<br />
CLOUDINARY_API_SECRET=<br /><br />

//Production or Development Server<br />
NODE_ENV=development or production<br /><br />

// Gmail Configurations<br />
GMAIL_PASSWORD=<br />
GMAIL_EMAIL=<br /><br />

// Frontend URL configurations<br />
FRONTEND_URL=<br /><br />

// Redis URL<br />
REDIS_URL=<br /><br />

// Socket or Worker Server<br />
NEXT_PUBLIC_SOCKET_SERVER=<br /><br />

Now to run the app type these commands in your command line in the App's dorectory:<br />

1. npm install<br />
2. npm run dev<br />
